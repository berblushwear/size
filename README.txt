BERRYBLUSH CATALOG - GITHUB PAGES

Contents: index.html, styles.css, app.js, catalog.json, size-charts/ (74 original JPG charts), .nojekyll.
All website and chart links are relative, so the catalog works under a GitHub Pages repository subpath.
No build tools, OpenAI account, API keys, database, or OpenAI hosting are required.
Fonts load from Google Fonts; system fonts are used when unavailable.

PUBLISH
1. Extract this ZIP.
2. Upload the extracted files and size-charts folder to the root of your GitHub repository. index.html must be in the repository root. Upload the contents, not the ZIP itself.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select the branch containing the files (usually main), select /(root), then Save.
5. Open the website address shown by GitHub once deployment finishes.

Keep all filenames and the size-charts folder structure unchanged. Viewing the catalog locally is best done through a local web server because catalog.json is loaded with fetch.

GitHub instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
